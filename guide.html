合唱リリックフラッシュ 使い方

歌詞と音楽記号を、音に合わせてパッと表示する練習アプリです

アプリを開く

このアプリでできること

  • 歌詞のフラッシュ表示 … 音が鳴っている間だけ、その単語が大きく出ます。文の全体は見えないので、覚えたかどうかを確かめられます。
  • 伸ばす長さがわかる … 2拍以上伸ばす音は〇の数で長さを表し、1拍ごとに●に変わります。
  • 強弱記号・音楽記号 … 今の強弱（p、mf など）を常に表示。次の強弱は2小節前から「NEXT」に出ます。クレッシェンド、rit.、フェルマータなども、その間だけ表示されます。
  • 練習に便利な操作 … パートの切り替え、ゆっくり再生、歌い出しへのジャンプ、前奏・間奏のスキップ、メトロノーム。
  • 歌詞の書き出し … 自分のパートの歌詞をテキストやPDFにできます（翻訳のメモなどに）。

はじめかた

  1. 共有されたURLを開くLINEなどで届いたアプリのURLを、スマホのブラウザ（iPhoneは Safari、Androidは Chrome）で開きます。
  2. ホーム画面に追加するアイコンからすぐ開けるようになります（1回だけでOK）。

    iPhone（Safari）

    1. 画面下の 共有（四角から矢印が出たマーク）をタップ
    2. ホーム画面に追加 をタップ
    3. 右上の 追加 をタップ

    Android（Chrome）

    1. 右上の ⋮ をタップ
    2. ホーム画面に追加（または アプリをインストール）をタップ
    3. 追加／インストール をタップ
    ホーム画面にできた「合唱リリック」のアイコンから開きます。
  3. 楽譜を選ぶ画面上の曲名（最初は「サンプル曲」）をタップ → ＋ 楽譜を選ぶ → 練習する曲の楽譜ファイル（.mxl や .musicxml）を選びます。
  4. 音源を選ぶ（音源ファイルがある曲だけ）同じ画面の ＋ 音源を選ぶ → 同じ曲の音源ファイル（.mp3 や .wav）を選びます。音源がない曲は、アプリが楽譜から作った音（合成音）で再生します。
  5. パートを選ぶ画面右上の パート をタップして、自分のパートを選びます。
  6. ▶ で再生あとは再生して、画面を見ながら歌うだけです。
ファイルがスマホに入っていないとき
楽譜・音源は合唱団のGoogleドライブにあります。ファイルを選ぶ画面で「Googleドライブ」を選べば、そのまま開けます。
iPhoneでドライブが出てこない場合は、Googleドライブのアプリでファイルの … → アプリで開く → "ファイル"に保存 で、いったんiPhoneに保存してから選んでください。

メトロノーム
  • 1今の強弱。まだ強弱記号が出てきていないところでは何も出ません。
  • 2クレッシェンド／デクレッシェンド。効果が続いている間だけ出て、線が進み具合に合わせて濃くなります。
  • 3次の強弱。変わる2小節前から表示されます。
  • 4発想記号など（rit.、dolce、フェルマータ など）。
  • 5拍子・テンポ・小節番号。
  • 6伸ばす長さ。〇の数が拍数で、1拍ごとに●になります。点線の〇は1拍に満たない部分（裏拍から始まる音など）です。
  • 7歌詞。音が鳴っている間だけ出ます。まだ歌っていない部分は薄く表示されます。

ボタンの使いかた

最初曲の頭にもどります。
前の歌い出しひとつ前のフレーズの頭にもどります。歌い出しの直後に押すと、さらにひとつ前へ。
▶再生／一時停止。
次の歌い出し次のフレーズの頭へ進みます。長い休みも飛ばせます。
メトロノームタップでオン／オフ。1拍目は「カッ」、ほかの拍は「コッ」と鳴ります。
×1（速度）再生の速さを ×0.5〜×1.25 から選べます。音の高さは変わりません。
バー動かすと、好きな位置へ移動できます。

設定（右上の つまみのマーク）

音量自分のパートと、ほかのパートの音量を別々に変えられます。
前奏・間奏をとばすオンにすると、自分のパートが長く休むところを自動で飛ばします。
曲を開いたときのパート楽譜を開いたときに最初に表示するパートです。
歌詞を書き出す今のパートの歌詞を、コピー・テキスト保存・PDF保存できます。
音源に合成音も重ねる音源を付けた曲で、アプリの合成音も一緒に鳴らします（ふだんはオフ）。

こまったとき

音が出ない（iPhone）

本体の横の消音スイッチ（マナーモード）がオンになっていないか確認してください。

前に開いた曲が消えた

アプリが覚えているのは、最後に開いた1曲（と、その音源）だけです。別の曲は、そのつど楽譜・音源を選び直してください。

音源が再生できない

mp3 か wav のファイルを選んでください。

歌詞が出ない

選んでいるパートに歌詞がない可能性があります。右上の「パート」を確認してください。

合唱リリックフラッシュ ／ 選んだ楽譜・音源はスマホの中だけで使われ、どこにも送信されません。
